# 答复交付组合包

[English](README.md) | 中文

在 **插件 → 更多** 中启用 **答复交付**，打开详情编辑 **额外工作要求**。保存后应用草稿；恢复默认会移除用户覆盖，回到继承值。关闭组合包会卸载运行时与界面，不改变其他工具。

本组合包加载[交付运行时](../deliver-response/README.zh.md)及[设置与答复展示](../client-ui-deliver-response/README.zh.md)，默认配置不启用。要求由现有配置系统保存，不引入独立存储。图标沿用标准通用插件图形。

## 模型体验

通过[交付运行时](../deliver-response/README.zh.md)间接影响模型；提示词、工具说明、预填交换及 token 开销由运行时负责，本组合包不另加模型内容。

#### KV Cache 影响

工作要求和每轮消息的变化由运行时负责，本组合包没有额外缓存影响。

## 已知限制与后续工作

- 这是默认关闭的实验性组合。原生工具交付及提供方限制见运行时文档；启用后仍不强制模型调用交付工具。
